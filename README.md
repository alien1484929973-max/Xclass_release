# XClass 产品下载

这里托管 XClass 可公开分发的安装包、作者工具包和版本说明。

访问本仓库的 **Releases**，选择所需预览版本，再从 **Assets** 下载：

| 文件 | 用途 |
|---|---|
| teacher-setup.exe | Windows 教师工作台 |
| teacher-linux-x64.AppImage | Linux x64 教师工作台，AppImage |
| teacher-linux-x64.deb | Linux x64 教师工作台，DEB |
| student-setup.exe | Windows 学生实验室 |
| student-android.apk | Android 学生实验室 |
| xclass-classroom-author.zip | 作者 Skill、协议、SDK、模板及校验/打包工具 |

`release-manifest.json` 记录每份文件的真实版本、构建来源、大小和 SHA256，`SHA256SUMS` 用于下载校验。各产品可以沿用不同版本，以逐文件清单为准。GitHub 自动生成的 Source code 压缩包只含本仓库说明，不是产品安装包或平台源码。

预览版本的安装、更新、设备兼容性和限制以该版本说明为准；预览发布不代表全部验收完成。

本仓库不包含平台源码历史、服务器部署资料、数据库、账号、教学数据或过山车项目。作者项目通过通用协议接入，不随产品发布。公开下载不代表授予平台源码开源许可；各附件内第三方声明继续适用。
